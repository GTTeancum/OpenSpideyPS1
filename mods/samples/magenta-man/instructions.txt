MAKE YOUR OWN SPIDER-MAN RESKIN

Start with a copy of this entire folder. Give the copy a new folder name,
such as my-spidey, and put it in mods/suits beside SpiderMan.exe.
The game includes six safe model bases: Spider-Man, Scarlet Spider, Symbiote
Spider-Man, Quick Change, Peter Parker, and Spider-Man 2's default Spider-Man.

1. Paint your costume

Open the PNG pictures in the textures folder with your image editor.
Recolor them or paint your own details, then save them as PNGs with the same
filenames. Keep the face, body parts and transparent areas in the same places.
You can use larger pictures for finer detail; 2048 x 2048 is supported.
Do not stretch just one side of a picture or change its proportions.

Need a painting guide? TEMPLATE contains copies with Blender's UV layouts
stamped over them. White outlines show where the model's faces use the picture.
Each guide has the same filename and size as its texture. The UV subfolder
also has clean outlines you can open as a separate layer in a supporting editor.
Use these as a reference while painting the clean pictures in textures.
Keep the guide lines out of your finished costume. The game ignores TEMPLATE.

2. Name it and choose its powers

Open suit.json in Notepad. Change only the text inside the quotation marks:

  id        A unique short label, such as my-spidey.
            Use lowercase letters, numbers and hyphens, with no spaces.
  name      Your costume's name in the list and under COSTUME: (18 characters max).
  comments  Your own message under COMMENTS:. Keep it short; three short
            lines will fit with any power choice. Text wraps automatically.
  model     The built-in model base. This example uses spiderman.
  profile   Whose powers to copy, using one of the choices below.

Leave version and the textures entries as they are. Those texture names match
the spiderman base. Any other base reskin must start with that model's matching
texture/template set. Keep the commas and quotation
marks in place. You do not need another JSON file or a model file.

Model choices:

  spiderman         Default SM1 Dreamcast Spider-Man.
  scarlet-spider    Dreamcast Scarlet Spider.
  symbiote          Dreamcast Symbiote Spider-Man.
  quick-change      Dreamcast Quick Change Spider-Man.
  peter-parker      Dreamcast Peter Parker.
  sm2-spiderman     Default SM2 Dreamcast Spider-Man, including web wings.

Power choices:

  spiderman         Normal Spider-Man powers.
  2099              Stronger attacks.
  symbiote          Unlimited webbing.
  captain-universe  Invincibility, stronger attacks and unlimited webbing.
  unlimited         Invisibility, toggled with L2.
  bagman            No web belt; carries only two web cartridges.
  scarlet           Normal Spider-Man powers.
  ben-reilly        Normal Spider-Man powers.
  quick-change      No web belt; carries only two web cartridges.
  peter-parker      No web belt; carries only two web cartridges.

GAME POWERS: is filled in automatically using the original costume's wording.
Your choice changes the powers, not your painted costume.

3. Try it

Save your changes and restart the game. Open SPECIAL, then COSTUME VIEWER.
Find your costume and select it. Reskins are always unlocked.

If it does not appear, check that its id is different from your other reskins,
that all the PNGs are still present, and that suit.json still has its commas
and quotation marks. Try shorter comments if the text will not fit.

To share your reskin, zip your costume folder with suit.json, instructions.txt
and the textures folder. The other player puts it in their mods/suits folder.
