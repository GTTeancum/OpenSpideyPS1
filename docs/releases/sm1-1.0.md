## Installation

1. Download the Spider-Man.zip release asset and extract it to a writable folder. Do not run the executable from inside the ZIP.
2. Keep the mods folder beside SpiderMan.exe.
3. Launch SpiderMan.exe and select your USA PlayStation BIN/CUE or ISO. Keep any BIN files referenced by a CUE together. The game checks the USA boot identity; no exact disc hash is required.
4. Allow first-run setup to extract the game assets. The game then starts; later launches use the extracted files.
5. Open OPTIONS > VIDEO SETUP to choose resolution, 4:3 or 16:9, and fullscreen on/off. Apply your changes.
6. Select included costumes under SPECIAL > COSTUME VIEWER.

## Requirements and notes

- Windows x64 and a working graphics driver.
- Your own USA PlayStation disc image for this game. Retail disc images and extracted retail game data are not included.
- Use an original raw dump to retain XA audio/video; cooked ISOs cannot restore discarded sectors.
- Keep the extracted game folder writable for setup, settings, and saves.
- Mod author credits remain in each suit's JSON and accompanying files.
- Targeted gameplay, renderer, and mod smoke checks have passed. Full playthroughs and long-duration stability are not certified.
